# Program Kit 0.9.10 release evidence

The release adds deterministic coverage for C4 projection parsing, canonical regeneration and
freshness, bootstrap-intake hash binding, invalid and missing DSL, Docker and Java discovery,
digest-pinned image availability, Keycloak port avoidance, Windows paths containing spaces, POSIX
quoting, repeated invocation, and exact cleanup without consumer-repository mutation.

Release packaging and clean installation prove that the new skill, launcher, managed tool profile,
and supporting references survive component and bundle distribution. Governance-state and
clean-consumer bootstrap regressions prove that assessment and final review packets expose the
viewer without weakening approval, ratification, or completion hashes.

With explicit user authorization, physical acceptance used Docker Desktop 29.0.1 and
`structurizr/structurizr:2026.06.28` at registry digest
`sha256:251905a1a2d73195e84b784966babc71b329223fdbb25368261a9e3ba39041c4`. Structurizr Local rendered
the clean-bootstrap System Context and Domain Context views on `127.0.0.1:8081` from a temporary
mount. The first diagram opened directly, review colors and proposed-state cues were visible, the
view switcher and legend worked, repeated invocation reused the session, and shutdown removed the
exact disposable container and temporary state.

That physical run also exposed a sandboxed-stop edge case that could delete the session record while
leaving its container running. The release preserves recoverable state whenever Docker cannot be
reached or confirms no removal, and an automated regression now covers that behavior.

Structurizr's surrounding application chrome remains upstream. Program Kit improves the generated
diagram styling, direct landing, navigation guidance, and safe lifecycle without introducing a
custom architecture editor or making visual tooling a bootstrap prerequisite.
